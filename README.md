# Riepilogo i7

Cruscotto personale, pubblicato con GitHub Pages.

- `index.html` e `motore.js`: la pagina.
- `dati/dati.cifrati.json`: i dati, scritti da un PC (salute ogni 15 minuti, tutto ogni 3 ore) e **cifrati** (AES-256-GCM). Senza la password non si leggono.

Nessun dato in chiaro va messo in questo repository.
